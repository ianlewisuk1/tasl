# TASL Hub

One fast, mobile-first home for Triangle Adult Soccer League standings, results, fixtures and fields.
Data is scraped on a schedule from the league's public TeamPass pages and tasl.us.

- `scraper/` — Python scraper and loaders (public pages only, no login)
- `web/` — Next.js site
- `prototype/` — standings design prototype (the visual spec)
- `REQUIREMENTS.md` — product requirements
